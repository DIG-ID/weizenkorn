  Breakpoints do design: mobile 393px · tablet 834px · desktop 1920px.
- GRELHA DESKTOP (confirmada com o overlay de grid do Figma, 2026-07-22):
    · Canvas 1919.46 (~1920).
    · Container/grid = 1820px · 12 colunas · coluna ≈ 133.3px (mostrada 134) ·
      gutter 20px · margens laterais ≈ 50px.  Aritmética: 12×133.3 + 11×20 = 1820.
    · Unidade (coluna+gutter) ≈ 154px; coluna N começa em x ≈ 50 + (N−1)×154.
    · IMPORTANTE: muitas secções recuam o conteúdo 1 coluna de cada lado →
      vivem nas colunas 2–11 (10 col ≈ 1520px de largura). NÃO confundir esse
      inset de conteúdo (1520) com a grelha-mãe (1820).
    · Tailwind: container max-width 1820px + px-~50; `.theme-grid` = grid-cols-12
      com gap-5 (20px EXACTO); conteúdo inset = col-start-2 col-span-10.
- GRELHA TABLET (overlay Figma, 2026-07-22):
    · Canvas 834. Container/grid = 700.25px (~700) · 6 colunas · coluna 100px ·
      gutter 20px · margens laterais ≈ 67px.  Aritmética: 6×100 + 5×20 = 700.
    · Tailwind: grid-cols-6 · gap-5 (20px, igual ao desktop) · px-~67.
- GRELHA MOBILE (overlay Figma, 2026-07-22):
    · Canvas 393. Container/grid = 321px · 2 colunas · coluna 150px · gutter 20px ·
      margens laterais = 36px.  Aritmética: 36 + 150 + 20 + 150 + 36 = 392 (~393).
    · Tailwind: grid-cols-2 · gap-5 (20px) · px-9 (36px).
- RESUMO GRELHA (gutter = 20px CONSTANTE em todos os breakpoints → gap-5):
    desktop 1920 → container 1820 · 12 col · coluna ~133 · margens ~50
    tablet   834 → container  700 ·  6 col · coluna  100 · margens ~67

6. MAPEAMENTO WORDPRESS (templates, CPTs, archives)
--------------------------------------------------------------------------------
DECISÃO ESTRUTURAL: com ~35 páginas desktop a partilharem as MESMAS secções
(page-hero, intro-panel, usp-band, quote-slider, cta-form, cross-links…),
templates fixos por página são inviáveis. Recomendação: **ACF Flexible Content**
(um leque de secções modulares reutilizáveis) montado num `page.php`/front-page,
com 2–3 page-templates só para os casos com lógica própria (Open positions,
Contact). As secções do ponto 3 são os "layouts" do flexible content.

TEMPLATES DE SISTEMA / RAIZ
  front-page.php   → Home (593:736). Ordem: hero-card → products (intro + range
                     cards) → usp-band → services (intro + card-venue Schreinerei/
                     Kreativatelier/Treuhand) → gastronomia ("zu allen Betrieben")
                     → locations-band → work&training (intro + job-teasers) →
                     about-teaser → footer(newsletter).
  page.php         → páginas com flexible content (a maioria dos interiores).
  404.php          → 404_desktop ("Oops!" + link Home).
  Legais (ABG/AGB, Data Policy, Impressum) → page.php + layout legal-content.

PAGE-TEMPLATES (lógica própria)

  page-contact.php        → dados de contacto + horários + google-map.

8. SUGESTÃO DE CUSTOM FIELDS (ACF)

FLEXIBLE CONTENT `page_sections` (layouts = secções do §3), padrão por layout:
  section_base       : { overline, title, tag(h1/h2), align, rule_color, links[] }
  hero_card          : { title, tagline, description, image, button }        (Home)
  page_hero          : { title, subtitle, image, variant }
  intro_panel        : { title, text }
  usp_band           : { title, items[]{ icon, label } }
  section_cards      : { section_base, cards[]{ image, title, text, link } }
  product_range_cards: { section_base, ranges[]{ image, title, excerpt, page } }
  quote_slider       : { quotes[]{ quote, name, role, image } }
  stories_references : { section_base, items[]{ image, title, text, link } }
  cta_form           : { title, text, form_id(CF7), variant(red/light) }
  faq                : { title, items[]{ question, answer } }
  offer_grid         : { section_base, items[]{ image, title, excerpt } }
  capabilities_grid  : { title, groups[]{ title, items[] } }
  service_info_downloads : { title, links[]{ label, url }, files[]{ title, file } }
  downloads          : { title, text, files[]{ title, description, file } }
  process_steps      : { section_base, steps[]{ title, text } }
  contact_person     : { image, name, role, phone, email, text }
  sales_points       : { title, retail[], enduser[], external_links[]{ label, url } }
  locations_band     : { section_base, venues[]{ image, title, excerpt, page } }
  gastronomy_detail  : { description, cta{label,url}, opening_hours[], address, map }
  values_grid        : { title, values[]{ icon, title, text } }
  video_feature      : { overline, title, text, poster, video_url }
  cross_links        : { title, items[]{ image, title, page } }
  donation_cta       : { title, text, button }
CPT `news`   : (core) title/content/thumbnail + { subtitle, gallery }, tax news_category
CPT `job`    : { job_type(tax), betrieb(tax/relation), pensum, excerpt, apply_contact }
CPT `product`: (se opção A) { gallery, category(tax), external_links[] }
Site options (ACF Options): socials, newsletter(Mailchimp), morada/contactos,
  mega-menu (colunas dinâmicas), footer legal.
